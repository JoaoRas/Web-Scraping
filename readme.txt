# Stellarcraft Scraper 

Este projeto foi desenvolvido como parte de um desafio técnico.

# Objetivo

Realizar web scraping da página de produto e extrair:

* Título
* Marca
* Categorias
* Descrição
* SKUs
* Especificações
* Reviews
* Média de avaliações

# Tecnologias utilizadas

* Python
* Requests
* BeautifulSoup

# Como executar

```bash
pip install requests beautifulsoup4
python script.py
```

# Saída

O script gera um arquivo `produto.json` com os dados estruturados.
